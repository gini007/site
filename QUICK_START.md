# 🚀 Quick Start Guide

## Option 1: Using the Batch File (Windows)
1. Double-click `start-app.bat` in the project folder
2. The script will automatically:
   - Activate Node.js v24.7.0
   - Install dependencies
   - Start the development server

## Option 2: Using PowerShell
1. Right-click in the project folder
2. Select "Run with PowerShell"
3. Run: `.\start-app.ps1`

## Option 3: Manual Steps
1. Open a new PowerShell window
2. Navigate to the project folder
3. Run these commands:
   ```powershell
   nvm use 24.7.0
   npm install
   npm start
   ```

## What You'll Get
- ✅ Modern React 18 app with TypeScript
- ✅ Smooth animations with Framer Motion
- ✅ Responsive design for all devices
- ✅ Interactive elements and hover effects
- ✅ Animated background with particles
- ✅ Professional styling with styled-components

## Troubleshooting
- **If nvm is not recognized**: Open a new PowerShell window
- **If npm is not recognized**: Run `nvm use 24.7.0` first
- **Port conflicts**: The app will automatically use the next available port

## Next Steps
